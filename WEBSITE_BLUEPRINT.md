# Europa Data Hub — Premium Website Redesign Blueprint (Elementor, No-Code Plan)

## 0) Design Direction (Reference-Inspired, Not Copied)
Use the reference site style principles (clear hierarchy, strong whitespace, concise B2B copy, visual proof, and guided CTAs) while keeping Europa Data Hub’s own messaging and services.

Core UX psychology to replicate:
- **Clarity first**: one clear promise above the fold.
- **Progressive trust**: proof appears early and repeatedly (logos, outcomes, testimonials, process).
- **Low-friction conversion**: primary CTA in hero + secondary CTA in each major section.
- **Executive scannability**: short headings, benefit bullets, visual cards, no long dense paragraphs.
- **European credibility**: privacy, compliance, reliability, responsiveness, and business formality.

---

## 1) Homepage Conversion Structure (High-Converting B2B Flow)
Recommended section order:

1. Sticky Header (Logo + nav + primary CTA)
2. Hero (value proposition + 2 CTAs + trust strip)
3. Client/Trust Logos strip
4. Service Pillars (5 core services)
5. Outcomes / KPI Impact section
6. “How We Work” 4-step process
7. Featured case studies (2–3)
8. Testimonials + social proof metrics
9. Why Europa Data Hub (European trust drivers)
10. Lead magnet / consultation CTA band
11. Contact section with optimized B2B form
12. Footer (legal + contact + quick links)

Purpose: move visitors from **What do you do?** → **Can I trust you?** → **Will it work for me?** → **How do I start?**

## 4) CTA and Lead Generation Strategy

### Primary CTA strategy
- Main CTA sitewide: **Book a Discovery Call**.
- Place in header, hero, mid-page, and pre-footer CTA band.

### Secondary CTA strategy
- “View Services”, “Request Case Study”, “Send Requirements”.
- For colder traffic, use downloadable lead magnet:
  - “Reporting Automation Readiness Checklist (PDF)”

### Lead capture funnel
1. Visitor clicks CTA.
2. Lands on dedicated contact/discovery page.
3. Fills smart form.
4. Auto-response email with expectations + timeline.
5. Manual follow-up within 1 business day.

### Conversion boosters
- Add microcopy near form: “No spam. No generic sales pitch. Practical recommendations only.”
- Add calendar booking option (Calendly/Google Calendar) beside form.

## 5) Optimized B2B Contact Form Fields
Use a multi-step or well-grouped form to reduce friction while qualifying leads.

**Essential fields:**
1. Full Name (required)
2. Work Email (required)
3. Company Name (required)
4. Company Size (dropdown: 1–10, 11–50, 51–200, 200+)
5. Role/Department (dropdown)
6. Service Needed (multi-select)
   - Data Analytics
   - Power BI Dashboards
   - Excel Automation
   - Data Cleaning
   - Reporting Automation
7. Current Challenge (textarea)
8. Preferred Start Timeline (ASAP, 2–4 weeks, 1–3 months, planning phase)
9. Budget Range (optional but recommended)
10. Consent checkbox (GDPR-compliant)

**Thank-you message:**
“Thank you. We’ve received your request and will reply within 1 business day with next steps.”

## 7) Color Palette and Typography
Reference-inspired but customized for Europa Data Hub.

### Color system
- **Primary Navy:** `#0F2742` (authority, B2B trust)
- **Primary Blue:** `#1E88E5` (technology, clarity)
- **Accent Teal:** `#12B3A8` (data/innovation signal)
- **Success Green (CTA alt):** `#2EBD59`
- **Text Dark:** `#1A1A1A`
- **Text Medium:** `#4B5563`
- **Background Light:** `#F7F9FC`
- **White:** `#FFFFFF`
- **Border/Subtle line:** `#E5EAF0`

### Typography
- **Headings:** Manrope or Inter (600–700)
- **Body:** Inter or Source Sans 3 (400–500)
- **Scale:**
  - H1: 52/60
  - H2: 38/46
  - H3: 28/36
  - Body Large: 20/32
  - Body: 18/30
  - Small text: 15/24

### Spacing system
- Section vertical padding: 88–120px desktop; 56–72px mobile.
- Max content width: 1200px.
- Consistent 8px spacing grid.

## 8) Exact Elementor Implementation Instructions

### Global setup
1. Elementor → Site Settings:
   - Set global colors from palette above.
   - Set global fonts and typography scale.
2. Theme Builder:
   - Create global Header and Footer templates.
3. Container settings:
   - Use Flexbox Containers.
   - Max width 1200px, centered.

### Homepage build order
1. **Header template**
   - Container: 3 columns (logo / nav / CTA).
   - Sticky: top; effects enabled.
2. **Hero section**
   - 2-column container (55/45).
   - Left: Heading widget, Text widget, Button row (2 buttons), Icon list trust line.
   - Right: Image widget (dashboard mockup).
3. **Logo strip**
   - Inner container with Image Carousel or icon/image row.
4. **Services**
   - Heading + 5 card containers.
   - Each card: Icon, H3, short text, text link.
5. **Outcomes band**
   - Background color contrast.
   - 4 counter/stat widgets.
6. **Process section**
   - 4 icon boxes with connector lines (or simple numbered cards).
7. **Case studies**
   - Posts/loop grid or manual cards.
8. **Testimonials**
   - Testimonial Carousel widget.
9. **Why us**
   - Icon list / checklist layout.
10. **CTA band**
    - Heading + supporting text + button.
11. **Contact block**
    - 2 columns: left form, right contact details + data handling bullets.
12. **Footer template**
    - Quick links, legal links, email, copyright.

### Responsive rules
- Tablet: hero converts to stacked layout, CTA remains above fold.
- Mobile: single-column cards, 16–20px side padding, sticky CTA optional.
- Keep button tap height >= 48px.

### Performance/quality controls
- Compress images to WebP.
- Limit animation (subtle fade only).
- Maintain WCAG AA contrast.
- Validate all forms and CTA links after publishing.
